# Janko-s-Temperature-trend-analysis
A python program which generate temperature trend using Giovanni datasets and create a folder containing all the output data

Steps:
 
  clone repo to a folder.
  
  run the analysis.py file
  
  it show info about input 7 giovanni files and create a folder named OUPUT containing statistic data and plot data

prerequisite:

    python

  python libraries:
  
    pandas, numpy, matplotlib, scipy, statsmodels, pymannkendall
    
  install these by:
    
      python -m pip install pandas numpy matplotlib scipy statsmodels pymannkendall
